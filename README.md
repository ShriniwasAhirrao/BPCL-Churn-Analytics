# ⛽️ Petrol Pump Churn Analysis

A machine learning project focused on analyzing customer churn for a family-owned BPCL petrol station. The goal is to identify at-risk customers, improve retention, and optimize sales strategies.

---

## 📂 Project Files

- **`churn_data_cleaned.csv`**  
  Preprocessed dataset used for training and evaluating churn prediction models.

- **`Cp Transaction History.csv`**  
  Raw transactional history data from the petrol pump. Includes customer behavior insights like frequency, spend, and last activity.

- **`Petrol Pump Churn Analysis.ipynb`**  
  Jupyter notebook covering end-to-end churn modeling:
  - Exploratory Data Analysis (EDA)
  - Feature Engineering
  - Model Building (Logistic Regression, Random Forest)
  - CLV Calculation
  - Business Recommendations

---

## 🎯 Key Highlights

- Identified 190+ high-risk churn customers
- Boosted retention rate by ~20%
- Increased overall fuel sales by ~15% through targeted re-engagement
- Used CLV segmentation to focus on high-value customers
